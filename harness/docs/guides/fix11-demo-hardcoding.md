# AI 코드 패치 시연 재료

`fix11-demo-hardcoding.patch`는 temp-box flaskr 기준으로 `app.config.update(app_config())` 바로 뒤에 개발용 서명 키와 loopback URL을 추가합니다. 샘플 앱 원본은 수정하지 않았습니다. 앱 저장소 현재 파일의 문맥이 다르면 해당 두 대입문만 같은 위치에 옮깁니다.

1. 사람이 앱 저장소 기능 브랜치에서 이 패치를 반영하고 prod로 PR을 merge합니다. 실제 비밀값을 사용하지 않습니다.
2. 관리자 페이지에서 AI 코드 수정 ON, `SECRET_KEY` 자동 공급·인벤토리 public_url을 확인합니다.
3. 승인 화면에서 원본 SHA, `secret_key`·`local_address` 대상, 필수 환경 키 이름·검사 결과·패치 해시와 계획을 확인하고 승인합니다.
4. ai-prod 후보와 빌드의 SHA 일치, 성공 릴리스의 파일별 패치 원장을 확인합니다.
5. 같은 파일을 바꾸지 않은 다음 run은 패치를 재사용합니다. 원본이 바뀌면 다시 제안합니다. OFF는 새 제안을 하지 않으며 기존 패치를 잃으면 승인 전 중단합니다.

이 변경은 이미지·박스 기능을 추가하지 않습니다. smoke `V2.box`는 앱 v2 기능이 있는 run에서만 별도로 선택합니다. 기본 검증 묶음은 그대로 유지합니다.
