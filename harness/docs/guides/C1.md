## 10/1 사용자 후속 확정

- CodeBuild는 `ai-prod` 후보 커밋 SHA를 `sourceVersion`에 고정한다. S3는 대체 경로다. C2 빌드 연결은 이 기준을 따른다.
- TLS 담당은 정준우다. ACM·443·리다이렉트·HSTS는 플랫폼 Terraform이 만들고 `ensure_tls`는 발급 완료·443 동작을 확인하며 불충족 시 실패한다. `ensure_tls`에서 직접 발급·변경하지 않는다.
- 트랙 대기 지점(`local_verified` 게이트·`ABORTED_AT_GATE`)은 제거하고 두 트랙을 독립 진행하며, 교차 검증은 둘 다 성공했을 때만 수행한다. **이 변경과 `prod` 감시·`ai-prod` 갱신·`deployed/*` 태그·`main` 갱신은 별도 브랜치 착수 지시 전까지 구현하지 않는다.**
- 이번 후속 반영은 결정 기록이다. 현재 TLS 코드는 AWS 설정 조회까지이며 실제 443 접속 동작을 확인한 것으로 보지 않는다. 기존 실행기·트리거 코드도 변경하지 않았다.

## 취합 때 필요한 결정

1. 생성기는 리소스 HCL만 넘기고 provider/backend/variable/output은 코드가 만들지(C-20), bundle SHA·저장 위치.
2. 플랫폼·앱 별도 run/승인. 현재 O1 저장소는 run당 infra 기록 하나다.
3. C-03 출력 이름·타입·필수 키와 생성 리소스 주소. C3 기존 ALB/ACM 이름, C2 ECS/CodeBuild/시크릿을 맞춘다.
4. C1 공유 모델·카탈로그·실행기 조립. 세션은 실행 시 주입하고 RunContext·DB에 저장하지 않는다.
5. TLS 소유권은 확정됐다. 플랫폼 Terraform에서 리소스를 만들고 `ensure_tls`는 확인만 수행하도록 생성기·provider를 연결한다. 공유 계약의 `apply` 모드 정리는 별도 조율 대상이다.
6. CodeBuild 기본 소스는 `ai-prod` 후보 커밋 SHA로 확정됐다. S3 대체 경로를 실제 연결할 때는 전용 버킷 읽기 범위가 필요하며, 현재 build 경계에는 추가하지 않았다.

- TLS path/query 보존·80 리스너의 추가 규칙 거절·조회 간 deadline 검사를 추가했다. 실제 앱 라우팅은 C3 범위, SDK 자격증명/DNS 호출 자체를 강제 중단하는 기능은 없다.
