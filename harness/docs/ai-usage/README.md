# 개발 과정 AI 활용 기록

> 기준: 앱 1개 구조(✅ 9/30 최신 개발자 문서 기준)

개발 과정에서 AI 코딩 도구(Claude Code, Codex 등)를 쓴 작업을 사람별로 기록합니다. 심사(AI 활용 10점, 팀 개발 20점)에 반영되는지는 확인하지 못했지만, 기록이 있어야 설명할 수 있습니다.

## 규칙

- 파일은 사람별로 하나: `docs/ai-usage/<역할>.md`(예: `o1.md`). **append만** 합니다. 사람별 파일이라 머지 충돌이 나지 않습니다.
- 항목 형식은 [_TEMPLATE.md](_TEMPLATE.md)를 복사해 씁니다.
- PR 본문은 `.github/pull_request_template.md` 형식을 따르고(지금 "AI 사용" 칸은 없음), "변경 내용"에 이 기록 위치를 적습니다. PR 번호를 기록에 남깁니다.
- 비밀값, 내부 URL, 개인 정보는 적지 않습니다. 프롬프트 전문 대신 요약을 적습니다.

## 무엇이 아닌가

- **git 메타데이터가 아닙니다.** 커밋 작성자와 Co-authored-by에는 AI를 넣지 않습니다(컨트리뷰터 목록 문제). AI를 썼다는 사실은 여기와 PR, README에 공개합니다.
- **제품 런타임 AI 비용과 다릅니다.** 제품이 실행 중에 부르는 AI(계획, 패치, 원인 분석, 보고 요약)의 사용량·비용은 `call_ai`가 기록해 결과 카드에 표시합니다.
