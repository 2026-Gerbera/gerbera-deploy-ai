# O1 AI 활용 기록

## 2026-09-30 | Codex | 하네스 최신화와 로컬 착수

- 요청: 최신 문서·사용자 결정 반영, 로컬 개발환경 구성, O1 우선 계약 정리.
- 사람이 결정한 것: 한 화면·한 번 승인, 대상별 기록 분리. O1 착수 기준 정리는 위임.
- AI 산출물: 독립 테스트와 계약 모델, 비Git 환경 준비 명령, 문서 정합성 수정. 실제 배포 기능 완성은 범위 밖.
- 검증 결과는 하네스 README의 현행 검증 기록을 참조한다. 사용자 요청으로 TDD 절차는 중단하고 기존·추가 테스트와 전체 품질 검사로 검증했다.

## 2026-09-30 | 최소 협업 규칙으로 조정

사용자 요청으로 이메일 허용목록·커밋 형식·브랜치명·main push·필수 PR 승인 제약을 제거했다. CI 자동 검사와 AI 작성자 표시 차단은 유지한다. GitHub 업로드·설정 변경은 수행하지 않았다. TDD 없이 기존 동작·변경 동작을 로컬 검사로 확인한다.

## 2026-09-30 | 하네스 루트 이동

사용자 요청으로 구형 MCP 하네스를 삭제하고 최신 하네스 148개 파일을 저장소 루트로 이동했다. 이동 직후 파일 해시 일치를 확인했다. Git 저장소·프로젝트명·설계 문서·조사 자료는 보존하고 상대 링크와 로컬 경로를 수정했다. 루트에서 가상환경을 다시 구성해 검증한다.

## 2026-09-30 | 사용자 경로 정정

최상위라는 요청은 저장소 루트에 `harness/` 폴더를 두라는 뜻이었다. 하네스를 이 폴더로 이동하고, 루트 GitHub Actions가 `harness/`를 검사하도록 변경했다. 로컬 훅과 setup도 상위 Git 저장소를 지원하도록 조정한다. 이전 루트 이동 기록은 경로 정정 전 이력이다.
