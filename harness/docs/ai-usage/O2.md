- AI 산출물: 직전 생성 번들의 HCL과 고정 오류 코드만 재입력하고, AI가 반환한 기존 파일 일부만 새 격리 번들에 병합하는 교정 흐름. 새 파일·이름 변경·전체 파일 재출력은 거부하고, 비밀값·Terraform state는 입력하지 않으며 병합 뒤 전체 검증·plan·사람 승인을 유지한다.
- 검증: 파일 보존·부분 교체·전체 재출력 거부 회귀 테스트와 전체 CI로 검증하며, 개발 에이전트는 Terraform 명령과 AWS plan/apply를 실행하지 않는다.

## 2026-10-03 | Codex | 신규 IAM 역할 plan 참조 해석

- 요청: 최초 인프라 Terraform plan 승인 요약이 `IAM_ROLE_UNKNOWN`으로 중단되는 문제 수정.
- 사람이 결정한 것: IAM 경계·최소 권한·Access Analyzer 검증은 그대로 유지하고, 미확정 값을 허용하는 범위는 코드의 직접 IAM 역할 참조로 제한.
- AI 산출물: 신규 `aws_iam_role_policy.role` 값이 plan 시점에 unknown이어도 Terraform configuration의 `aws_iam_role.<name>.id/name` 직접 참조를 기존 역할 변경과 연결한다. 직접 참조가 없거나 모호하면 기존처럼 거부한다.
- 검증: unknown role ID 성공 및 참조 없는 경우 거부 회귀 테스트, 인프라 런타임·정책 집중 테스트와 전체 CI로 검증한다. Terraform 명령과 AWS plan/apply는 실행하지 않았다.
