# 온프렘 관리 페이지 운영 결정 — 2026-10-03

관리자 웹 `src/ddak/web` 개발은 양서윤에서 정준우가 위임받아 담당하며 변경 목록을 서윤님께 공유한다.

## 확정된 경계

- 기존 프로젝트·환경 설정과 제품 비밀 저장소로 운영값을 입력한다. 선택적 환경변수 덮어쓰기는 유지하되 온프렘 시작 프로필은 환경변수를 새로 만들지 않는다. 따라서 웹 저장값을 기본 프로필이 가리지 않는다.
- `필요 도구 설치` 버튼과 현재 계획 해시 승인 뒤에만 gitleaks 8.30.1을 설치한다. 플랫폼별 archive SHA-256은 코드에 고정하고 함께 내려받은 checksum 문서를 신뢰 근거로 쓰지 않는다. 제품 전용 버전 경로에서 절대 경로로 실행하며 설치 버전·archive SHA·바이너리 SHA·시각을 기록한다. 자동 실행·업데이트·sudo·시스템 경로·셸 프로필 변경은 없다.
- 같은 버튼은 기본 제품 전용 buildx 빌더 생성·확인을 할 수 있다. 이름을 직접 지정한 기존 빌더는 검사만 한다. 전역 기본 빌더를 바꾸지 않는다. 특권 QEMU/binfmt 등록은 하지 않으며 amd64·arm64 미지원은 명시적으로 표시한다.
- uv는 >=0.12.20,<0.13인지 검사만 한다. OS·uv·Docker·SSH·CLI 설치·로그인, VM 생성, 접근 수단/Tailscale 준비는 제품 밖 사전 준비다. 이를 완료한 시연 운영과 새 PC 무설치를 같은 것으로 보고하지 않는다.
- 앱 커밋 작성자 이름·이메일은 운영자가 입력한다. 비어 있으면 실제 저장소 준비를 차단한다. `merge`·`commit`·`commit-tree` 명령의 `-c user.name/user.email`에만 적용한다. Git 설정 파일과 작성자 환경변수에 값을 쓰지 않는다.
- 앱 저장소 push 인증은 제품 SecretVault의 저장소 URL에 묶인 토큰만 쓴다. Git credential helper는 해당 GitHub HTTPS host/path만 응답하며 기존 helper·대화형 인증과 trace를 비활성화한다. helper는 Python의 현재 디렉토리 모듈 검색을 끄고 제품 경로를 사용한다. Git global/system/환경 주입 설정을 격리하고 include/worktree의 별도 HTTP 인증 header도 거부한다. 토큰을 인자·환경변수·공개 설정·화면에 넣지 않는다. 로컬 bare/FAKE는 별도 검증 경로다.
- 기존 툴 이름·입력·이벤트·deploy.yaml은 변경하지 않는다. 아래 추가 설정은 10/3 승인 조건을 충족한다.

## 추가 공개 설정

| 이름 | 타입 | 기본값/누락 처리 | 화면 위치 |
|---|---|---|---|
| buildx_builder | string 또는 null, 안전한 이름 64자 이하 | null이면 기존 제품 전용 이름; 지정된 빌더 없으면 검사 실패 | 초기 연결 설정 / 로컬 빌더 이름 |
| git_author_name | string 또는 null, 120자 이하 | null; REAL 준비에서 설정 필요 | 초기 연결 설정 / 커밋 작성자 이름 |
| git_author_email | string 또는 null, 254자 이하 | null; REAL 준비에서 설정 필요 | 초기 연결 설정 / 커밋 작성자 이메일 |
| ai_timeout_s | 유한 양수 float 또는 null, 최대 300초 | null이면 기존 Settings 기본/선택적 덮어쓰기 유지 | 초기 연결 설정 / AI 호출 제한 시간 |

토큰은 설정 모델 키가 아니다. `git_push_token`은 기존 SecretVault의 0600 값으로 저장하고 공개 API는 등록 여부만 반환한다. 토큰 저장 전에 프로젝트 저장소 URL이 필요하다. URL을 바꾼 경우 토큰을 다시 등록한다. 이전 화면에서 추가 필드 없이 저장해도 새 키는 지우지 않는다.

## 남은 결정/공유

- DB 별도 승계 원장은 기존 설계 문서대로 미구현이다. DB 라벨 변경을 위해 컨테이너를 재생성하지 않는다. 새 setup 툴/파라미터를 추가하는 구현은 별도 계약 확인 대상이다.
- uv·QEMU 미지원은 표시만 한다. 제품이 해당 설치를 대신한다는 주장은 금지한다.
- 생성 인프라 교정의 4096자 분할 계약은 통합 인계서의 설계만 유지한다.
- 서윤님께 공유: setup 신규 필드·Git 토큰 폼·도구 설치 기록·상세 검사 표·공용 connection 상태 매크로. 디자인 재작업 시 CSRF·값 비노출·프로젝트/버전 전달을 보존한다.
