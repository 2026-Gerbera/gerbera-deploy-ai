# 로컬 리소스 매핑 제안

정준우 승인(2026-10-04). 규칙이 처리하지 않는 로컬 리소스에 AI 매핑을 제안한다.
이번 버전은 제안 표시까지 지원한다.

- 분석 단계에서 Python AST의 로컬 Redis·브로커·메일 주소와 SQLite 파일 흔적을 찾는다.
  기존 패치가 키를 확정한 위치, IMG_DIR, DATABASE_URL과 환경변수 읽기는 제외한다.
- 흔적이 없으면 호출하지 않는다. 입력은 종류·파일·줄·키 이름이며 값이나 원문을 넣지 않는다.
  요청은 공통 관문을 사용하고 최대 5초, 재시도 없이 실행한다. 실패는 값 없는 로그로 남기고
  기존 분석·계획·승인·배포 흐름을 유지한다.
- 응답의 허용 대상은 s3/rds/elasticache/sqs/ses/none이다. 근거 ID가 없거나 허용 대상이
  아니면 버린다. 승인 조회 데이터 `infra.mapping_suggestions`에 저장하며 각 항목의
  `executable`은 항상 false다. 화면은 이 데이터를 설명용으로 사용할 수 있다.
- 분석 출력·툴·이벤트 계약은 바꾸지 않는다. 제안은 승인용 컨텍스트와 조회 파일에 보존하며
  인프라 생성 신호·정책·권한 경계에 연결하지 않는다. 실제 저장소 생성은 기존 S3 규칙 경로다.
