## 결정 기록 방법

1. `docs/decisions/_TEMPLATE.md`를 복사해 `docs/decisions/<YYYY-MM-DD>-<주제>.md`로 만듭니다(예: `2026-09-30-single-app.md`). 일련번호를 쓰지 않습니다(번호 충돌 방지).
2. 맥락, 선택지와 장단점, 결정, 이유, **반대 의견**, 되돌리는 조건을 적습니다. 팀 개발 점수 증빙이 되므로 반대 의견을 지우지 않습니다.
3. 결정이 하네스에 영향을 주면(위 표의 마지막 열) 같은 PR에서 하네스 파일을 고치고, 이 표의 상태 칸을 "결정됨(날짜, 문서 링크)"으로 바꿉니다.
4. 계약에 영향을 주면 계약 변경 절차([03](03_깃-규칙과-AI-컨트리뷰터-차단.md) E-2)를 따릅니다.
