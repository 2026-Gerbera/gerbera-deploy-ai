# single-app: 앱 1개 구조 기준 설계 정리본

## 이 디렉토리는 무엇인가

| 항목 | 내용 |
|---|---|
| 목적 | 2026-09-30 결정 장부를 기준으로 다시 쓴 **최신 정리본**입니다. MCP 서버 없이 파이썬 앱 1개(관리 웹 + 계획 + 계획 검증 + 실행기 + 툴 레지스트리)로 만드는 구조를 전제로 합니다. 9/30 새벽 결정(장부 21~24)으로 **Terraform도 AI가 짜고, IAM은 AI 설계 → 사람 승인 → 생성**입니다. 9/30 낮 결정(장부 25~36)으로 **이미지 저장소 기본은 Docker Hub, Dockerfile이 없으면 AI가 생성, 개선 배포는 환경 정보를 코드가 읽어 주입, CD는 공통 인터페이스 + provider, 라이브 데모의 인프라 장면은 v2 새 시크릿 추가**입니다. |
| 쓰임 | 팀원에게 나눠 줄 개발 문서의 **기준**입니다. 각자 이 문서와 최상위 `harness/`를 보고 무엇을 만들지 알 수 있게 하는 것이 목표입니다(장부 19). |
| 구조 상태 | 최신 개발자 문서 기준 앱 1개입니다. MCP 어댑터는 P2입니다. |
| 우선순위 | **최신 사용자 결정·O1 착수 결정 > 현재 하네스 계약 > 개발자 문서 > 이전 결정 장부 > 기존 `docs/`·`research/`**. 문서와 하네스 코드가 다르면 멈추고 묻습니다. |
