### 2-1. 김준석 (O2)

**P0 체크리스트**
- [ ] `receive_deploy_request`: run_id, 소스 스냅샷(zip + sha256), 토글 상태 고정. P0 입구는 버튼/CLI. 채팅 의도 JSON은 P1 💭

- [ ] `analyze_project`(규칙): 마이그레이션 탐지·lint(추가형만), env 키 정적 스캔(`os.environ`, `os.getenv`, `app.config[...]`, `from_mapping`), 라우트(`/auth/*`), 세션 사용, 하드코딩 비밀·개발값(v2 `SECRET_KEY=dev`) → facts + `facts_hash`
- [ ] step 카탈로그 + `skip_allowed(facts)` 규칙(정준우와 공동, [02](02_파이프라인과-계획.md)). 💭 `deploy.infra.cloud`(인프라 요구 해시가 같으면 제외, 다르면 강제 포함 V22 — v2는 SECRET_KEY로 포함, ✅ 장부 32), `deploy.dbinit.cloud` 포함
- [ ] 💭 인프라 요구 도출: `analyze_project` 출력에 `infra_needs`(tier·포트·DB 엔진·시크릿 키 **이름**·헬스 경로)와 `infra_inputs_hash`. 유상준의 `generate_infra` 입력(C-17)
