# 02. 디렉토리와 담당 (충돌 방지용, 9/30 밤 · 커밋 `7612150` 기준)

> 원칙: **내 디렉토리만 고친다.** 다른 디렉토리는 안쪽 파일을 직접 import하지 말고 `__init__.py`의 공개 함수만 쓴다. ★ 공용은 채팅방에 먼저 알리고 작게 PR, 정준우가 확인한다. AI 호출은 `core/ai`(call_ai)로만, 허용된 디렉토리에서만.

## 제품 코드 `src/ddak/`

| 디렉토리 | 내용 | 담당 |
|---|---|---|
| ★ `core/` (contracts, registry, config, redact, logging) | 공통 계약·레지스트리. 바꾸면 `make -C harness contracts` | 공용 |
| `core/ai/` | `call_ai`(cli/api/replay), Jev | 김준석 |
| `core/store.py`, `core/snapshots.py` | 실행 기록 DB, 스냅샷 해시 | 정준우 |
| `plan/intake/` | 요청 접수·스냅샷 | 김준석 |
| `plan/detect/` | 변경 탐지(스냅샷 내용 해시) | 김준석 |
| `plan/analyze/` | 분석·키 분류(Jev) | 김준석 |
| `plan/planner/` | 계획 생성 | 김준석 |
| `plan/validate/` | 계획 검증 | 김준석 |
| `plan/patch/` | AI 코드 수정(P0) | 장민영 |
| `plan/dockerfile/` | Dockerfile 생성·검사 | 장민영 |
| `executor/` | 실행기(병렬 트랙, 대기, 잠금, 롤백, 상태) | 정준우 |
| ★ `cd/` (interface.py, dispatch.py, tools/) | CD 공통 인터페이스, 환경 무관 툴 | 정준우 관리 |
| `cloud/infra/` | AI Terraform 생성·검증·plan·apply, 기존 리소스 탐지 | 유상준 |
| `cloud/build/` (+ `registries/`) | CodeBuild 멀티 아키텍처, Docker Hub 푸시(기본)·ECR(옵션) | 안승환 |
| `cloud/deploy/` | ECS 배포·롤백(`ecs.py`), 시크릿(`secrets.py`), 앱 DB·마이그레이션(`database.py`) | 안승환 |
| `cloud/tls/` | HTTPS 연결 | 유상준 |
| `cloud/health/` | 클라우드 헬스·TLS 검증 | 양서윤 |
| `onprem/deploy/` | 컨테이너 배포·롤백(`containers.py`), 설정 주입(`config.py`), 마이그레이션(`migrate.py`) | 정준우 |
| `onprem/provision/` | 온프렘 서버·컨테이너 준비, 앱 DB·계정 | 김준석 |
| `onprem/inventory/` | 인벤토리(tier별 주소) 읽기 | 김준석 |
| `verify/smoke/` | 스모크 | 장민영 |
| `verify/compare/` | 교차 검증 | 장민영 |
| `verify/diagnose/` | 원인 분석(AI) | 장민영 |
| `verify/report/` | 결과 카드·보고 | 양서윤 |
| `web/` (routes/, templates/, static/) | FastAPI 관리 페이지 | 양서윤 |
| `integrations/slack/` | Webhook 알림(P0-라이트) | 담당 미정 💭 |
| `ops/` | 사전 점검·데모 초기화 | 정준우 (클라우드 정리는 유상준) |

- AI를 import할 수 있는 곳: `plan/analyze`, `plan/planner`, `plan/patch`, `plan/dockerfile`, `verify/diagnose`, `verify/report`, `cloud/infra`, `core/ai`. 나머지(`executor`, `cd`, `cloud/deploy·tls·health·build`, `onprem/*`, `ops`)는 금지이며 CI(import 규칙)가 막는다.
- 각 디렉토리의 `__init__.py`에 계약 모양의 빈 구현(호출 시 "미구현")이 있다. 그 함수를 채우는 것부터 시작한다.

## 개발 도구 `harness/`

| 디렉토리 | 내용 | 담당 |
|---|---|---|
| `apps/sample-app/` | flaskr v1 / v2 | 장민영 |
| `compose/local/` | 온프렘 컨테이너 구성 | 김준석 (실행 연결은 정준우) |
| `infra/terraform/` | 고정 틀(상태 버킷·권한 경계), AI Terraform 결과 위치 | 유상준 |
| `tests/unit/<디렉토리>/` | 각자 자기 디렉토리 테스트(구조가 `src/ddak`와 같음) | 디렉토리 담당 |
| ★ `tests/contract/` | 계약 테스트 | 공용 |
| `fixtures/` | 테스트 데이터. 파일명에 역할 코드 붙이기 | 사용하는 사람 |
| `contracts/schemas/` | 자동 생성 스키마 | 직접 수정 금지 |
| `docs/guides/<역할>.md`, `docs/ai-usage/<역할>.md` | 역할별 가이드·AI 사용 기록 | 각자 |
| `docs/decisions/` | 결정 기록(새 파일로 추가) | 누구나 |
| ★ `scripts/`, `Makefile`, `.githooks/` | 공용 명령·훅 | 정준우 |
