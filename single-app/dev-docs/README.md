| [추정] / 확인 필요 | 실측 전 숫자 / 아직 확인 못 함 | 발표·문서에 확정처럼 쓰지 않습니다 |

## 문의·결정 채널

| 무엇 | 어디로 | 비고 |
|---|---|---|
| 내 역할 범위 질문 | 짝 → 해당 계약의 주는 사람 | 계약 번호(C-xx)로 말하면 빠릅니다([01](01_공통-계약.md) 15절) |
| 문서와 문서, 문서와 코드가 다름 | 팀 채팅방에 `NEEDS_CONTEXT`로 30분 안에 | 필요한 결정, 선택지, 각각의 영향을 적습니다. 계약을 혼자 바꾸지 않습니다 |
| 막혀서 진행 불가 | 팀 채팅방에 `BLOCKED` | 막힌 원인, 시도한 것 |
| 결정 기록 | 결정 장부([../docs/00](../docs/00_결정-요약.md)) | 문서 정리는 정준우가 하고 있습니다(테크 리드 공식 지정 없음, ✅ 장부 18) |
| 계약·레지스트리 변경 승인 | 미정(N19) | 저장소가 생기면 `contract-change` 이슈·라벨 + PR로 |
| AWS 실제 호출 | 통합 창(💭 10/1 오후, 10/2 리허설)에만. 시작·끝을 팀 채팅방에 알림 | 실제 클라우드 대상 run은 한 번에 한 명(실행기 잠금은 PC마다 따로라 공유되지 않음). 10/1 저녁: 공유 환경(온프렘 VM·ECS) 배포도 한 번에 한 명, 채팅방에 알림(동시 실행 잠금은 추후) |
| 비밀값(API 키·토큰) | 공유 금고 → 각자 로컬 파일 | 채팅방·Notion에 붙여넣지 않습니다 |
